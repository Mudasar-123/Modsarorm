# Mudasar ORM Services

Premium Online Reputation Management website built with React, Tailwind CSS, and Framer Motion.

## Features

- Dark luxury theme with gold, neon green, and glassmorphism effects
- Particle background and smooth scroll animations
- AI Reputation Scanner dashboard with sentiment analysis UI
- Appointment booking system with WhatsApp integration
- Testimonial carousel with before/after ratings
- Interactive FAQ accordion
- AI chatbot assistant demo
- Floating WhatsApp button
- Sticky responsive navigation
- Typing text effect in hero section
- Animated counters and statistics
- Fully mobile responsive
- SEO optimized

## Tech Stack

- **React** — UI framework
- **Tailwind CSS v4** — Utility-first styling
- **Framer Motion** — Animations
- **tsParticles** — Particle background
- **React Icons** — Icon library
- **React CountUp** — Animated number counters
- **Vite** — Build tool

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
